لغة صفحات الطرز المتراصة (CSS) وتطورها في تصميم وتطوير المواقع الإلكترونية

إعداد الطالبة: سلمى ممدوح عبد الغفار رحيم

السكشن: 75

المجموعة: (ج)

1. المقدمة العامة

شهدت شبكة الإنترنت وتطوير المواقع ثورة حقيقية منذ بداية تسعينيات القرن الماضي وحتى وقتنا الحالي. في البدايات، كانت الصفحات عبارة عن نصوص مجردة تحتوي على روابط شعبية (Hyperlinks) وتنسيقات بسيطة للغاية تُدار بالكامل عبر لغة HTML.

ومع توسع استخدام الشبكة العنكبوتية، برزت الحاجة الماسة إلى فصل المحتوى والهيكل عن الشكل والمظهر الجمالي. من هنا جاءت لغة CSS (Cascading Style Sheets) أو ما يُعرف باللغة العربية بـ "صفحات الطرز المتراصة".

تُعد CSS الحجر الأساسي والعمود الفقري لتصميم واجهات المستخدم (UI) على الشبكة، حيث تتيح للمطورين والمصممين التحكم الكامل في الألوان، والخطوط، والتخطيطات (Layouts)، والأبعاد، والمسافات، بالإضافة إلى المؤثرات البصرية والحركية.

2. الخلفية التاريخية وتطور CSS

تم اقتراح CSS لأول مرة بواسطة هاكون فيوم لي (Håkon Wium Lie) في 10 أكتوبر 1994 أثناء عمله مع تيم بيرنرز لي في منظمة CERN.

كان الهدف هو إنشاء لغة تظليل بسيطة ومرنة تمكن المتصفحات من عرض الصفحات بشكل موحد وجذاب.

مراحل التطور والإصدارات

CSS 1 عام 1996

أصبح توصية رسمية من منظمة W3C (World Wide Web Consortium)، وتضمن الإصدار الأول خصائص أساسية مثل:

  • خطوط النصوص وأحجامها.
  • ألوان النصوص والخلفيات.
  • الهوامش (Margins) والحواشي (Padding) والحدود (Borders).

CSS 2 & CSS 2.1 عام 1998 - 2011

شهد هذا الإصدار دعماً للمواقع متعددة وسائط العرض (Print, Screen)، ومفهوم التموضع Absolute/Relative positioning، ونصوص Z-index، ودعم أعمق للجداول ولغات الكتابة المختلفة.

CSS 3 منذ عام 1999 وحتى الآن

تم تقسيم CSS3 إلى وحدات متخصصة (Modules) مستقلة لتسهيل التطوير والتحديث، وتضمنت ميزات مثل:

  • الأركان الدائرية (Border Radius) والظلال (Box-Shadow).
  • التدرجات اللونية (Gradients).
  • التخطيطات الحديثة: Flexbox و CSS Grid.
  • الحركة والتدرج الزمني (Animations & Transitions).
  • التجاوب مع الشاشات المختلفة عبر استعالمات الوسائط (Media Queries).

3. المفهوم الأساسي والبنية الهيكلية (Syntax)

تعتمد CSS على قاعدة بسيطة تتكون من المحدد (Selector) وكتلة التصريح (Declaration Block). 

selector {
    property: value;
    property: value;
}

مكونات قاعدة CSS

  1. المحدد (Selector): يشير إلى عنصر HTML المراد تطبيق التنسيق عليه.
  2. الخاصية (Property): السمة التنسيقية المراد تغييرها مثل Color و Font-size.
  3. القيمة (Value): الإعداد المحدد للخاصية مثل Red و 16px.

4. طرق ربط CSS بملفات HTML

توجد ثلاث طرق رئيسية لربط تنسيقات CSS بصفحات HTML:

أ. التنسيق الداخلي السطري (Inline CSS)

يتم إضافته مباشرة داخل عنصر HTML باستخدام الخاصية style. 

<p style="color: blue;">هذا نص أزرق</p>

المميزات: مفيد للاختبارات السريعة.

العيوب: يصعب صيانته ويخل بمبدأ فصل المحتوى عن التصميم.

ب. التنسيق الداخلي (Internal / Embedded CSS)

يُكتب داخل عنصر <style> في رأس صفحة HTML داخل <head>.

ج. التنسيق الخارجي (External CSS)

يُكتب الكود في ملف مستقل بامتداد .css ويتم ربطه بالصفحة باستخدام العنصر <link>. 

<link rel="stylesheet" href="style.css">

المميزات: إمكانية إعادة استخدام الملف لجميع صفحات الموقع، وسهولة التعديل والصيانة، وتحسين سرعة تحميل الموقع عبر التخزين المؤقت (Caching).

5. المحددات (Selectors) وأنواعها

تتيح المحددات في CSS اختيار عناصر معينة بدقة عالية.

المحددات الأساسية (Basic Selectors)

  • محدد العنصر (Element Selector): يستهدف جميع العناصر من نوع معين مثل h1 و p.
  • محدد الفئة (Class Selector): يبدأ بنقطة ويستهدف العناصر ذات كلاس معين مثل .btn.
  • محدد المعرف (ID Selector): يبدأ بعلامة # ويستهدف عنصراً فريداً واحداً مثل #header.
  • المحدد العام (Universal Selector): العلامة * وتستهدف جميع العناصر في الصفحة.

المحددات المركبة والمتقدمة

  • محدد الأبناء المباشرين (Child Selector >).
  • المحددات الزائفة (Pseudo-classes) مثل :hover و :focus و :nth-child().
  • العناصر الزائفة (Pseudo-elements) مثل ::before و ::after.

6. نموذج الصندوق (Box Model)

يُعد Box Model المفهوم الأهم في CSS لتحديد المساحات وتخطيط العناصر. يتكون كل عنصر في HTML من صندوق يتألف من أربعة أجزاء متداخلة:

  1. المحتوى (Content): المساحة التي يظهر فيها النص أو الصورة.
  2. الحشوة الداخلية (Padding): المساحة الشفافة الفاصلة بين المحتوى والحدود.
  3. الحدود (Border): الإطار المحيط بالحشوة والمحتوى.
  4. الهامش الخارجي (Margin): المساحة الشفافة الفاصلة بين العنصر والعناصر المجاورة له.

7. خصائص الخطوط والنصوص والألوان

أ. تنسيق الخطوط (Typography)

  • font-family: لتحديد نوع الخط.
  • font-size: لتحديد حجم الخط.
  • font-weight: للتحكم في سماكة الخط.
  • font-style: لتحديد ما إذا كان الخط مائلاً أم عادياً.

ب. تنسيق النصوص (Text Styling)

  • text-align: لمحاذاة النص.
  • text-decoration: لإضافة خطوط تحت أو فوق أو عبر النص.
  • line-height: لتحديد المسافة العمودية بين الأسطر.
  • letter-spacing و word-spacing: للتحكم في المسافات بين الحروف والكلمات.

ج. الألوان وخلفيات العناصر

  • color: لتحديد لون النص.
  • background-color: للتحكم في لون الخلفية.
  • background-image: للتحكم في صور أو تدرجات الخلفية.

8. خصائص التموضع والعرض (Display)

أ. خاصية العرض (display)

  • block: يبدأ في سطر جديد ويشغل العرض الكامل المتاح.
  • inline: يأخذ مساحة بقدر محتواه فقط ولا يبدأ في سطر جديد.
  • inline-block: يجمع بين ميزات الاثنين.
  • none: يخفي العنصر تماماً من الصفحة.

ب. خصائص التموضع (Positioning)

  • static: التدفق الطبيعي للعنصر.
  • relative: يتم تحريك العنصر بالنسبة لمكانه الأصلي.
  • absolute: يتم تحريك العنصر بالنسبة لأقرب أب يمتلك تموضعاً غير static.
  • fixed: يثبت العنصر في مكان محدد بالنسبة لنافذة المتصفح.
  • sticky: هجين بين relative و fixed بناءً على موضع التمرير.

9. أنظمة التخطيط الحديثة: Flexbox

يُعرف رسمياً بـ Flexible Box Layout، وهو نظام تخطيط أحادي الاتجاه (إما صف أو عمود) تم تصميمه لتوزيع العناصر داخل الحاويات وتسهيل محاذاتها حتى مع تغير أحجام الشاشات ديناميكياً.

المفاهيم الأساسية لـ Flexbox

  • Flex Container: العنصر الأب الذي نطبق عليه display: flex;
  • Flex Items: العناصر الابنة المباشرة داخل الحاوية.

أهم خصائص Flexbox

  • flex-direction: لتحديد اتجاه المحور الرئيسي.
  • justify-content: لتوزيع العناصر على طول المحور الرئيسي.
  • align-items: لمحاذاة العناصر على المحور التقاطعي.
  • flex-wrap: للتحكم في التفاف العناصر.

10. أنظمة التخطيط المتقدمة: CSS Grid

يُعد CSS Grid Layout نظام تخطيط ثنائي الاتجاه (صفوف وأعمدة معاً)، مما يجعله أداة قوية لتصميم الهياكل الكبرى والصفحات المعقدة.

المفاهيم الأساسية

  • Grid Container: تُفعل باستخدام display: grid;
  • الصفوف والأعمدة: تُحدد عبر خصائص مثل grid-template-columns و grid-template-rows.

مميزات CSS Grid

  • استخدام وحدة القياس fr (Fraction) لتقسيم المساحات بنسب مرنة.
  • إمكانية تداخل العناصر (Overlapping).
  • تحديد مواقع العناصر بدقة عبر أرقام الخطوط أو أسماء المناطق.

11. التصميم المتجاوب واستعلامات الوسائط (Media Queries)

مع تنوع أجهزة المستخدمين مثل الهواتف الذكية والأجهزة اللوحية والحواسيب المحمولة، أصبح Responsive Web Design ضرورة حتمية لضمان ظهور الموقع بشكل مثالي على كافة الشاشات.

تسمح استعالمات الوسائط (@media) بتطبيق قواعد تنسيق CSS مختلفة بناءً على خصائص جهاز المستخدم مثل عرض الشاشة والارتفاع ودقة العرض. 

body {
    background-color: white;
}

@media screen and (max-width: 768px) {
    body {
        background-color: #f0f0f0;
    }

    .sidebar {
        display: none;
    }
}

12. الحركات الانتقالية والتأثيرات الحركية

أ. الانتقالات (CSS Transitions)

تسمح بتغيير خصائص العنصر بشكل سلس وتدريجي عند حدوث حدث معين مثل تمرير الفأرة :hover.

  • transition-property: الخاصية المراد تطبيق التأثير عليها.
  • transition-duration: مدة التأثير.
  • transition-timing-function: سرعة التسارع والتباطؤ.
  • transition-delay: فترة التأخير قبل بدء التأثير.

ب. الحركات والرسوم المتحركة (CSS Animations)

تتيح للمطورين بناء حركات معقدة ومستقلة باستخدام قاعدة @keyframes لتحديد مراحل الحركة بدقة من البداية (0%) إلى النهاية (100%). 

@keyframes slideIn {
    0% {
        opacity: 0;
        transform: translateY(-20px);
    }

    100% {
        opacity: 1;
        transform: translateY(0);
    }
}

.box {
    animation: slideIn 1s ease-in-out infinite alternate;
}

13. المتغيرات في CSS (CSS Custom Properties / Variables)

من أحدث وأقوى الإضافات في لغة CSS إمكانية تعريف واستخدام المتغيرات البرمجية محلياً وعالمياً، مما سهل إدارة الألوان والأحجام وتحديثها في مكان واحد. 

:root {
    --primary-color: #3498db;
    --main-font-size: 16px;
}

body {
    background-color: var(--primary-color);
    font-size: var(--main-font-size);
}

الفوائد الرئيسية

  • تقليل التكرار في الأكواد (DRY Principle).
  • تسهيل إنشاء وتفعيل مظهر الوضع الليلي (Dark Mode) ديناميكياً.

14. تحسين الأداء وأفضل الممارسات في كتابة كود CSS

  1. تصغير وتجميع الملفات (Minification & Bundling): إزالة المسافات الزائدة والتعليقات وضغط الملفات لتقليل حجم الحزم المنقولة عبر الشبكة.
  2. تجنب المحددات المفرطة في التعقيد: الابتعاد عن السلاسل الطويلة جداً في المحددات.
  3. استخدام أدوات ما قبل المعالجة: مثل Sass و LESS لتنظيم الأكواد واستخدام الدوال الحسابية والتداخلات.
  4. الفصل الذكي للملفات: تقسيم الأكواد إلى وحدات صغيرة (Modular CSS) مثل ملفات خاصة بالتخطيط والأزرار والألوان.

15. الخاتمة والنتائج والتوصيات

الخاتمة

شهدت لغة صفحات الطرز المتراصة (CSS) تطوراً هائلاً من مجرد أداة بسيطة لتلوين النصوص وإضافة الخطوط في تسعينيات القرن الماضي، لتصبح نظاماً هندسياً متكاملاً يدعم أنظمة التخطيط المتقدمة مثل Flexbox و Grid، والرسوم المتحركة التفاعلية، والتصميم المتجاوب مع كافة الأجهزة الذكية.

لقد نجحت CSS في تحقيق الهدف الأسمى بفصل الهيكل البرمجي (HTML) عن العرض الجمالي والمظهر المرئي، مما رفع من كفاءة وموثوقية تطوير تطبيقات الويب الحديثة.
